# Installed Three.js API facts

Verified directly against the installed `three@0.187.0` source. Paths below are relative to `node_modules/three/`. These are current contracts, not guesses about migration dates.

| WebGL version | `WebGLRenderer` uses WebGL2. Its source explicitly says WebGL1 has not been supported since r163. | `src/renderers/WebGLRenderer.js:60-63`, `:409-413` |
| Context MSAA | `antialias` is a constructor option, default false. It is forwarded as a WebGL context attribute. Requesting it does not specify a sample count. The test reads actual `gl.SAMPLES`; it does not assume 4x. | `src/renderers/WebGLRenderer.js:73-86`, `:390-413` |

| PCF filtering | Current PCF creates a comparison depth texture with linear filtering. | Render statistics | WebGL `renderer.info.render` has frame, calls, triangles, points, lines. Triangle counts multiply by instance count. | Statistics scope | The automatic reset happens before shadow rendering. Our explicit reset counts the shadow and color draws together. `programs.length` is an allocated program count, not a draw count. These fields are the WebGL info implementation, not the differently shaped common/WebGPU implementation. | `src/renderers/WebGLRenderer.js:1742-1750`; `src/renderers/webgl/WebGLInfo.js:61-67` |

There are no `mergeBufferGeometries` / `mergeBufferAttributes` exports in this installed module. Merging requires compatible attributes and consistent indexing. It returns null on incompatibility. We convert box geometry to non-indexed form before merging it with generated non-indexed roof geometry. | `examples/jsm/utils/BufferGeometryUtils.js:149-183`, `:373-415`, `:1508-1522`; `src/core/BufferGeometry.js:1109-1175` |
| Instancing | Constructor is `InstancedMesh(geometry, material, count)`. `setMatrixAt` writes the matrix array; callers must set `instanceMatrix.needsUpdate = true`. Bounding volumes may need recomputation after matrix changes. We disable frustum culling for the small fixed diorama so animated bounds cannot go stale. | `src/objects/InstancedMesh.js:30-57`, `:110-115`, `:146-150`, `:331-342` |
| Capsules | Installed constructor is `CapsuleGeometry(radius, height, capSegments, radialSegments, heightSegments)`. Height is the middle section, not the full capsule. Placeholder people use radius .28 m and middle height .9 m before per-instance height variation. | `src/geometries/CapsuleGeometry.js:20-29`, `:64-69` |

No `Math.random`, `Date`, or `performance.now` calls exist in our scene, geometry, label, layer, time-model or RNG modules. Clocks occur only in the UI driver and measurement harness. Three.js internally creates identifiers independently; those identifiers do not place or animate geometry. Round 4 removes GTAO imports and rejects any non-off AO option.

## Look-development additions

- **VSM resources and support:** r187 creates an RG half-float shadow target and a native floating-point depth texture. It explicitly does not support VSM for point lights. This project uses a directional light. `src/renderers/webgl/WebGLShadowMap.js:218-242`.
- **VSM softness:** two separable blur passes read `LightShadow.radius` and `LightShadow.blurSamples`. The loop has fixed offsets, not a time-dependent seed. Round 4 chooses radius 7 and 16 samples. `src/renderers/webgl/WebGLShadowMap.js:384-427`; `src/renderers/shaders/ShaderLib/vsm.glsl.js:16-48`.
- **VSM caveat:** receivers also render into the shadow map. Ghost meshes therefore remain neither casters nor receivers. The VSM shader contains an explicit light-bleeding remap, so a noise-free result is not a physically exact area-light shadow. `src/renderers/webgl/WebGLShadowMap.js:528`; `src/renderers/shaders/ShaderChunk/shadowmap_pars_fragment.glsl.js:216-250`.
- **Previous ghost experiment:** the old module retains depth-selected visible/hidden line passes. Round 4 does not import or instantiate it and has no ghost/tray.
- **Wide-line support ships:** `LineMaterial` and `LineSegments2` are installed WebGL addons, not native wide GL lines. `worldUnits=false` selects screen widths; `linewidth` is documented in pixel units. The vertex shader offsets quads using viewport resolution. `LineSegments2.onBeforeRender` supplies that viewport size. Round 4 boundary lines use 1 drawing-buffer pixel at 1080p, 2 at 2160p, with renderer pixel ratio 1. `examples/jsm/lines/LineMaterial.js:179-255`, `:444-450`, `:512-560`; `examples/jsm/lines/LineSegments2.js:419-427`.
- **Scene labels:** a full-resolution `CanvasTexture` backs a transparent, tone-mapping-disabled `MeshBasicMaterial` in a separate orthographic HUD pass. It declares sRGB. The world still uses ACES; the warm off-white glyphs do not. Labels are canvas text, not DOM screenshots or system-font sprites. `src/textures/CanvasTexture.js:26`; `src/materials/Material.js:458`.
- **Clickable alignment:** `Vector3.project(camera)` supplies the world anchor's screen position. The film/live label bounds and accessible HTML hit area share one measured canvas layout. `src/math/Vector3.js:499-501`.
- **Perspective framing:** constructor arguments are vertical FOV, aspect, near and far. FOV is in degrees. The overview uses vertical FOV 25° and elevation 27°. `src/cameras/PerspectiveCamera.js:25-55`.
- **Shadow-only set floor:** `ShadowMaterial` is otherwise transparent and can receive shadows. It defaults to transparent and black, with ordinary material opacity. `src/materials/ShadowMaterial.js:4-18`, `:48-63`.
- **Seeded value variation:** physical shaders contain `<begin_vertex>` and `<color_fragment>` hooks. Our world-coordinate albedo shader adds seeded 1.5/4/8 cm grain/crumb/pebble variation, subtle scraping and 1 cm laminations, attenuated by screen-space derivatives at distance. Broad variation is ±8%; micro terms are additional, not an ±8% total bound. Only the continuation below the lowest ring blends toward the plinth albedo. `src/renderers/shaders/ShaderLib/meshphysical.glsl.js:40`, `:183`; `src/renderers/shaders/ShaderChunk/color_fragment.glsl.js:2-4`.
- **GTAO experiment, not assumed deterministic:** the installed constructor takes scene, camera, width, height, G-buffer parameters, AO parameters and denoise parameters. It creates fixed magic-square noise and a second `SimplexNoise` texture. The latter defaults to `Math` and constructs a randomized permutation table. Raw repeat/scrub/cross-launch results decide the experiment, not its name. `examples/jsm/postprocessing/GTAOPass.js:45-56`, `:140-142`, `:382-418`, `:691-719`; `examples/jsm/math/SimplexNoise.js:14-36`.

## Local font and Canvas verification

Pinned own-repository font URLs, commits, SHA-256 hashes and intact OFL files are in `public/fonts/PROVENANCE.md`. A uses Inter SemiBold; B uses Source Serif 4 Semibold for era names and Source Sans 3 Semibold for dates/callouts. Required faces finish loading before the scene is initialized; film fallback is forbidden.

Normal `@font-face` declarations have no numeric feature override. A separate Source Sans numeral alias declares `"tnum" 1, "lnum" 1` and is selected only while drawing digit runs. Names render as whole strings in the normal face. Canvas additionally uses equal digit advances and does not assume CSS `font-variant-numeric` inheritance. Runtime metrics retain all ten advances and cap sizes.

Browser API reference: https://developer.mozilla.org/en-US/docs/Web/API/FontFace/featureSettings .
